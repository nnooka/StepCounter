# StepCounter

StepCounter is a small browser app that helps you explore historical walking data exported from the Mi Fitness app.

## Features

- Import Mi Fitness export data (`.csv` or `.json`)
- Visualize daily, weekly, monthly, and yearly totals
- View average steps per day, week, month, and year
- Use built-in demo data to quickly explore the dashboard

## Run locally

1. Open `index.html` in your browser.
2. Upload your Mi Fitness export file.

## Test

npm test
